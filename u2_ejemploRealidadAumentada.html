Introducción

La realidad aumentada es una tecnología que permite incorporar elementos digitales al entorno físico mediante dispositivos como teléfonos celulares, tabletas o computadoras. A través de la cámara, el usuario puede observar su entorno y visualizar objetos virtuales que se integran en la pantalla. Para esta actividad se desarrolló un ejemplo de realidad aumentada utilizando un modelo tridimensional de un astronauta y un marcador visual que puede reconocerse mediante la cámara de un celular. También se incorporó un código QR para facilitar el acceso al ejemplo desde otros dispositivos.

El desarrollo se realizó utilizando herramientas web que permiten mostrar modelos 3D, generar códigos QR y controlar algunos elementos de la interfaz mediante JavaScript. En este documento se explica cómo se utilizaron estas herramientas y cuál fue su función dentro del proyecto.

Herramientas utilizadas

Para desarrollar esta actividad se utilizaron HTML, CSS, JavaScript y algunas bibliotecas externas que permiten trabajar con modelos tridimensionales y códigos QR.

HTML5

Se utilizó para estructurar la actividad y colocar los elementos que forman parte de ella, como el visor del modelo 3D, la imagen del marcador, el espacio destinado al código QR y los mensajes de instrucciones.

CSS3

Se utilizó para establecer la apariencia de la interfaz que acompaña al ejemplo. Entre sus funciones se encuentran la organización de la barra superior, los mensajes que aparecen en pantalla y los ajustes visuales para facilitar la consulta desde un dispositivo móvil.

JavaScript

Se utilizó para controlar el comportamiento de algunos elementos de la actividad. Mediante este lenguaje se genera el código QR, se establece el enlace al ejemplo y se controla la aparición de un mensaje dependiendo de si el marcador Hiro es detectado o deja de estar visible.

Model Viewer

Es una herramienta que permite visualizar modelos tridimensionales directamente desde una página web. En este proyecto se utilizó para mostrar un modelo 3D de un astronauta y habilitar las opciones de realidad aumentada disponibles en el dispositivo.

QRCode.js

Es una biblioteca de JavaScript utilizada para generar el código QR que dirige al ejemplo de realidad aumentada.

Incorporación del modelo tridimensional

Uno de los elementos principales de la actividad es un modelo tridimensional de un astronauta. Para mostrarlo se utilizó la etiqueta <model-viewer>, que permite integrar modelos 3D dentro de una página web.

El modelo utilizado se encuentra en formato GLB y se obtiene desde el sitio Model Viewer. En el código se establece su ubicación mediante el atributo src, mientras que el atributo alt proporciona una descripción del contenido.

También se habilitaron algunas propiedades para controlar su visualización. La opción camera-controls permite modificar la vista del modelo mediante los controles de la cámara, mientras que auto-rotate hace que el astronauta gire automáticamente.

Además, se agregó el atributo ar, que habilita la función de realidad aumentada, y se establecieron los modos compatibles mediante ar-modes. En este caso se incluyeron WebXR, Scene Viewer y Quick Look, dependiendo de las características y compatibilidad del dispositivo utilizado.

Uso del marcador Hiro

Otro elemento de la actividad es el marcador Hiro, una imagen que se utiliza como referencia visual para el ejemplo de realidad aumentada.

Dentro de la página principal se incorporó la imagen del marcador con una anchura de 220 píxeles. También se agregó una alternativa de carga desde un repositorio público en caso de que la imagen almacenada localmente no se encuentre disponible.

El usuario puede mostrar el marcador en la pantalla de una computadora o imprimirlo para utilizarlo durante la prueba. Posteriormente, al abrir el ejemplo desde el celular y dirigir la cámara hacia el marcador, el sistema puede reconocer su presencia.

Para controlar esta parte se utilizó JavaScript. El código obtiene los elementos identificados como marcador-hiro y mensaje-marcador, y establece dos eventos:

  • markerFound: se ejecuta cuando el marcador es detectado. En ese momento se agrega la clase oculto al mensaje de instrucciones.
  • markerLost: se ejecuta cuando el marcador deja de detectarse. En ese caso se elimina la clase oculto y el mensaje vuelve a aparecer.

Esto permite que las instrucciones se muestren mientras el marcador no está siendo reconocido y desaparezcan cuando la cámara lo detecta.

Generación del código QR

Para facilitar el acceso al ejemplo desde un teléfono celular se incorporó un código QR mediante la biblioteca QRCode.js. En JavaScript se establece una variable llamada URL_PUBLICA, que permite definir una dirección pública para el ejemplo. Cuando esta variable no contiene una dirección, el programa utiliza como destino el archivo ejemploAR.html, tomando como referencia la ubicación actual de la página.

Posteriormente, se obtiene el contenedor donde se mostrará el código QR y se genera la imagen con las dimensiones de 180 por 180 píxeles. También se establecen los colores negro y blanco para facilitar su lectura.

Además de generar el código, el programa coloca la dirección correspondiente en un enlace visible dentro de la página. De esta manera, el usuario puede acceder al ejemplo escaneando el QR o utilizando directamente el enlace.

Por último, se agregó una comprobación para identificar si la página se abrió desde una dirección local. Si el navegador utiliza el protocolo file: o se encuentra en localhost o 127.0.0.1, se muestra un aviso para informar que el proyecto se está ejecutando localmente y que todavía no tiene configurada una dirección pública.

Diseño de la interfaz mediante CSS

Para acompañar el funcionamiento del ejemplo se utilizaron diferentes reglas CSS que organizan los elementos que aparecen en pantalla.

La barra superior se configuró para permanecer fija en la parte superior del dispositivo. Se utilizaron propiedades como position: fixed, display: flex y justify-content: space-between para distribuir las instrucciones y el enlace de navegación.

También se estableció un fondo con degradado en tonos azules, texto blanco y espacios entre los elementos para mantener una presentación clara.

En la parte inferior se encuentra el mensaje relacionado con la detección del marcador. Este elemento tiene una posición fija, un fondo azul oscuro y texto centrado. Cuando JavaScript agrega la clase oculto, su opacidad cambia a cero y deja de recibir interacciones mediante el puntero. También se agregó una transición de 0.3 segundos para que el cambio de visibilidad sea más suave.

Estos estilos permiten mantener visibles las instrucciones durante el uso de la cámara y organizar los elementos sin que interfieran demasiado con la visualización.

La actividad cuenta con distintos elementos que permiten acceder y visualizar el ejemplo de realidad aumentada.

Desde la página principal se puede consultar el modelo tridimensional del astronauta y utilizar las opciones disponibles para visualizarlo. También se muestra el marcador Hiro y un código QR que dirige al archivo del ejemplo para abrirlo desde un teléfono celular.

Una vez abierto el ejemplo en el dispositivo, el usuario puede utilizar la cámara para trabajar con el marcador. El código JavaScript permite detectar cuándo este aparece o desaparece y modificar el mensaje de instrucciones según corresponda.

De esta manera, se integran el modelo tridimensional, el marcador visual y los elementos de navegación para presentar una actividad relacionada con la realidad aumentada.

Conclusión

El desarrollo de esta actividad permitió conocer algunas herramientas que se pueden utilizar para incorporar modelos tridimensionales y funciones de realidad aumentada dentro de un sitio web. Durante el proceso se utilizó Model Viewer para integrar el modelo del astronauta, QRCode.js para generar un código de acceso y JavaScript para controlar los eventos relacionados con la detección del marcador y la visualización de mensajes. Por su parte, CSS permitió organizar la interfaz y adaptar sus elementos a la pantalla del dispositivo. La actividad también permitió comprender la importancia de elementos como los marcadores visuales y la compatibilidad de los dispositivos al momento de desarrollar experiencias de realidad aumentada mediante tecnologías web.
