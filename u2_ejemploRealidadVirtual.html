Ejemplo de realidad virtual

Introducción

La realidad virtual es una tecnología que permite representar entornos tridimensionales generados por computadora, en los cuales es posible observar e interactuar con diferentes elementos digitales. Su aplicación se encuentra presente en ámbitos como la educación, el entretenimiento, la capacitación y la simulación de situaciones.

En este proyecto se desarrolló un ejemplo básico de realidad virtual con el propósito de mostrar cómo se puede construir un escenario tridimensional mediante herramientas de desarrollo web. Para ello se utilizaron HTML, CSS y la biblioteca A-Frame, que permite incorporar elementos tridimensionales directamente en una página web.

El resultado consiste en un entorno virtual compuesto por un cielo, un suelo y diferentes figuras geométricas. Algunos de estos objetos cuentan con animaciones que permiten apreciar el movimiento dentro del escenario. A lo largo de este documento se describe el proceso de desarrollo, las herramientas utilizadas y la manera en que se integraron para obtener el resultado final.

Herramientas utilizadas

HTML5

Se utilizó para construir la estructura de la actividad y colocar los elementos que forman parte de la escena. Dentro del código se encuentran las etiquetas de A-Frame que permiten agregar el cielo, el suelo, el texto y las figuras geométricas.

CSS3

Se utilizó para darle formato al espacio donde se muestra la escena. En este caso, se configuró el tamaño del visor, sus bordes y la forma en que se adapta cuando se abre la página desde una pantalla más pequeña.

A-Frame 1.4.0

Es la herramienta principal para crear el entorno tridimensional. Se integró mediante un enlace a su biblioteca y permitió agregar objetos, modificar sus características y establecer animaciones utilizando etiquetas dentro del HTML.

Desarrollo del escenario virtual

El escenario se encuentra dentro de la sección correspondiente a la actividad 5 de la página. Para comenzar a construirlo se agregó la biblioteca de A-Frame al documento HTML y posteriormente se utilizó la etiqueta <a-scene>, que es donde se colocan todos los elementos que forman parte del entorno.

La primera parte fue darle una apariencia al espacio. Para esto se utilizó <a-sky>, con un color azul claro que funciona como fondo, y <a-plane>, que representa el suelo mediante una superficie verde. También se agregó un texto en la parte superior con la leyenda "MTC - Realidad Virtual", utilizando la etiqueta <a-text>.

Una vez establecido el escenario, se incorporaron tres figuras geométricas: un cubo, una esfera y un cilindro. Cada una se colocó en una posición diferente para que pudieran distinguirse fácilmente.

El cubo se agregó mediante la etiqueta <a-box> y se le asignó un color azul. La esfera se creó con <a-sphere>, utilizando un color amarillo y un radio de 0.8 unidades. Por último, el cilindro se incorporó con <a-cylinder>, al que se le asignó un color azul marino, una altura de 1.5 unidades y un radio de 0.5 unidades.

Para colocar cada figura dentro del escenario se modificaron sus posiciones mediante los atributos correspondientes. Esto permitió distribuirlas horizontalmente, dejando el cubo a la izquierda, la esfera en el centro y el cilindro a la derecha.

Aplicación de CSS

Además de construir el escenario, fue necesario establecer el espacio que ocuparía dentro de la página. Para esto se utilizó la clase .visor, definida en el archivo de estilos CSS.

A este contenedor se le asignó una anchura del 100 % y una altura de 380 píxeles. También se agregaron bordes, esquinas redondeadas y un margen para separarlo de los demás elementos de la página.

Dentro de este contenedor se configuró la escena de A-Frame para que ocupara todo el espacio disponible. También se agregó una adaptación para dispositivos con pantallas de hasta 700 píxeles de ancho, donde la altura del visor cambia a 300 píxeles.

Estos ajustes permiten que el escenario se integre correctamente con el resto del sitio y conserve un tamaño adecuado al visualizarlo desde diferentes dispositivos.

Al abrir la actividad en el navegador, A-Frame carga los elementos definidos en el HTML y muestra el escenario tridimensional dentro del visor. Se puede observar el fondo azul claro, el suelo verde, el texto y las tres figuras geométricas.

El cubo gira de manera continua, mientras que la esfera sube y baja repetidamente. El cilindro permanece en su lugar durante toda la visualización.

Con estos elementos se consiguió construir un entorno virtual sencillo en el que se aplicaron algunos conceptos básicos del desarrollo tridimensional, como la posición de los objetos, sus dimensiones, orientación y animación.

Conclusión

La realización de este ejemplo permitió poner en práctica el uso de herramientas web para construir un entorno tridimensional. Durante el desarrollo se utilizó HTML para integrar los elementos de la escena, CSS para establecer la presentación del visor y A-Frame para crear los objetos y agregarles movimiento. Aunque el escenario es sencillo, su construcción permitió conocer cómo se pueden representar figuras geométricas dentro de un espacio virtual y modificar sus características mediante código. También fue útil para familiarizarse con A-Frame y comprender cómo funciona al trabajar junto con HTML.
